# Equipment CRUD — Derby Database

A Java Swing desktop application for managing equipment records (name, department, purchase date, condition, usage status, and price) backed by an Apache Derby database, connected manually via JDBC.

## Features

- Manual database connection via a dedicated **Connect to Database** button — the form and CRUD controls stay locked until a connection is established
- Full CRUD operations against a `TBL_EQUIPMENT` table:
  - **Insert** new equipment records
  - **View All** records in a sortable table
  - **Update** an existing record by selecting its row
  - **Delete** a record with a confirmation prompt
- Click-to-populate: selecting a row in the table auto-fills the form fields for editing
- Input validation for required fields, date format, and numeric price, with clear error dialogs instead of silent failures
- Status labels that reflect connection state and the outcome of the last action

## Tech Stack

- **Java** (Swing for the GUI)
- **Apache Derby** (network server mode, via `jdbc:derby://`)
- **JDBC** — `Statement` for static queries, `PreparedStatement` for parameterized inserts/updates/deletes, `ResultSet` for reading query results

## Database Setup

The app expects a Derby database named `DailyDB` running on `localhost:1527`, with a table shaped like this:

```sql
CREATE TABLE APP.TBL_EQUIPMENT (
    EQUIPMENT_ID   INT GENERATED ALWAYS AS IDENTITY (START WITH 1, INCREMENT BY 1) PRIMARY KEY,
    NAME           VARCHAR(100),
    DEPARTMENT     VARCHAR(100),
    PURCHASE_DATE  DATE,
    "CONDITION"    VARCHAR(50),
    IN_USE         BOOLEAN,
    PRICE          DOUBLE
);
```

> **Note:** `CONDITION` must be double-quoted in SQL statements — it behaves as a reserved token in Derby's grammar and causes syntax errors if left unquoted.

Default connection credentials used by the app (see `DB_URL`, `DB_USER`, `DB_PASSWORD` constants in `EquipmentGUI.java`):
- URL: `jdbc:derby://localhost:1527/DailyDB`
- User: `app`
- Password: `123`

Update these constants to match your own Derby setup before running.

## Running the App

1. Start your Derby Network Server (e.g. via NetBeans' Services panel, or `startNetworkServer` from the command line).
2. Compile and run `EquipmentGUI.java` — the `main` method launches the Swing UI on the Event Dispatch Thread.
3. Click **Connect to Database** to establish the connection and unlock the form.
4. Use **Insert**, **View All**, **Update**, **Delete**, and **Clear Fields** to manage records.

## Notes

- The date field expects the format `yyyy-MM-dd`.
- `EQUIPMENT_ID` is auto-generated by the database (identity column) and is never supplied by the application on insert.
